Конфиденциальность

У CUSTOS нет телеметрии, авторам программа ничего не отправляет. Ваши файлы уходят только туда, куда указывают задания: в выбранные вами папки, на серверы и в облачные диски, и на сайт мониторинга, если вы подключите к нему программу.

Одно включено по умолчанию: раз в день служба CUSTOS спрашивает GitHub (api.github.com), не вышла ли новая версия. В запросе только название программы; GitHub видит IP-адрес этого компьютера. Новая версия ставится, только когда администратор нажмёт «Обновить».

Выключить проверку: «Настройки» > «Обновления» > снимите «Проверять новые версии на GitHub раз в день». Компьютер, подключённый к сайту мониторинга, GitHub вообще не спрашивает.
