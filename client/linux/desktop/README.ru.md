# Предварительная версия CUSTOS для рабочего стола Linux

[English](README.md)

## Установка на Debian, Ubuntu и Linux Mint

Пакет рассчитан на Debian 12 и 13, Ubuntu 22.04, 24.04 и 26.04 и совместимые версии Linux Mint. Для службы нужен systemd, для окна — сеанс X11 или XWayland.

1. В GitHub войдите в свою учётную запись. На вкладке **Actions** откройте успешный запуск **Linux desktop preview** для нужной версии. В разделе **Artifacts** скачайте ZIP с именем `custos-linux-desktop-preview-deb-amd64` или `custos-linux-desktop-preview-deb-arm64`. Для обычной ВМ на ПК с Intel или AMD выберите **amd64**, для 64-разрядного ARM — **arm64**.
2. Извлеките файл `.deb` из ZIP, откройте его в программе установки пакетов и нажмите **Установить**. Если обработчика пакетов в live-системе нет, откройте терминал в папке с файлом и выполните `sudo apt install ./имя-файла.deb`, подставив имя скачанного файла.
3. Откройте CUSTOS из меню приложений. На новой машине пакет устанавливает и запускает службу резервного копирования через systemd. В live-сеансе без сохранения изменений пакет и настройки будут доступны до перезагрузки.
4. Если хотите управлять новой машиной через Monitor, скопируйте строку подключения со страницы **Установка → Windows и macOS**. На Linux выполните `sudo custos connect 'строка подключения'`, подставив скопированное значение. Подтвердите машину в Monitor и создайте задание. Если агент уже подключён, его задания появятся в окне.

Если вы ранее добавили ярлык из архива командой `add-menu-entry.sh`, удалите личный ярлык `${XDG_DATA_HOME:-$HOME/.local/share}/applications/org.custos.DesktopPreview.desktop`, чтобы меню открывало установленную копию.

Для обновления агента, установленного из этого пакета, установите более новую версию `.deb`. Если агент ранее установили через Monitor, пакет использует существующую службу, а Monitor по-прежнему может её обновлять.

## Архив только с графическим окном

Соберите предварительную версию из корня репозитория на Linux с .NET 10 SDK и GNU `tar`:

```sh
bash client/linux/build-desktop-preview.sh
tar -xzf client/artifacts-linux/desktop-preview/custos-linux-desktop-preview-x64.tar.gz
./custos-linux-desktop-preview-x64/custos-gui
```

В архив входит среда выполнения .NET. Программа использует системные glibc, ICU и графические библиотеки. Окно
открывается через X11. В сеансе Wayland нужен XWayland. Агент резервного копирования Linux устанавливается отдельно.
Запускайте окно от своего пользователя и храните распакованные файлы вместе. Окно подключается к локальному агенту
через `/var/run/custos.sock`, а агент проверяет права доступа в обычном порядке. Для тестового агента с другим
сокетом задайте при запуске окна его доверенный абсолютный путь в `CUSTOS_SOCKET`.

В предварительной версии доступны список заданий, история, журналы и управление выполнением. Настраивайте задания
и агент в Monitor. Для восстановления используйте Monitor или `custos restore`.

Для проверки окна без агента запустите `custos-gui --demo` с демонстрационными данными.

Чтобы добавить ярлык в меню приложений, запустите `./custos-linux-desktop-preview-x64/add-menu-entry.sh`. Ярлык
указывает на распакованную папку и доступен вашему пользователю. При переносе папки запустите скрипт снова. Для
удаления ярлыка удалите файл `org.custos.DesktopPreview.desktop` из
`${XDG_DATA_HOME:-$HOME/.local/share}/applications`.

Первый аргумент скрипта сборки задаёт архитектуру (`x64` или `arm64`), второй позволяет указать папку результатов.
Иконка PNG размером 256 пикселей взята из `client/src/Custos.Desktop/Assets/custos.ico`.

| Архитектура и сеанс | Что проверено |
| --- | --- |
| x64, Debian 13, X11 (Xorg) | Окно с демонстрационными данными, ярлык в меню и загрузка задания из локального тестового агента |
| ARM64, сборка на x64 | Исполняемый файл и нативные библиотеки для AArch64. Проверка запуска ещё предстоит |
| XWayland | Проверка запуска ещё предстоит |
